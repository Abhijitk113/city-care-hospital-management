# City Care Hospital Management System

A web-based Hospital Management System developed using Python, Flask, SQLite, HTML and CSS.

## Features

- Admin login and dashboard
- Patient registration and management
- Doctor registration and management
- Appointment booking and doctor availability checking
- Billing management with automatic bill issue dates
- Payment status management: Pending, Overdue and Paid
- Form validation for patient and doctor details

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run Locally

1. Install Python.
2. Install dependencies using `py -m pip install -r requirements.txt`.
3. Run the application using `py app.py`.
4. Open `http://127.0.0.1:5000` in your browser.

## Project Purpose

This project was developed for academic purposes to demonstrate basic hospital administration and database management through a web application.

**Note:** Use demonstration data only. Do not enter real patient medical information into a public demonstration website.
